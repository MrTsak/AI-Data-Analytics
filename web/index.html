What does the data show about diabetes?

This educational project starts from an initial set of 100,000 records. After removing 3,854 duplicate records and 18 records with “Other” in the gender field, 96,128 records were used. Two machine-learning models were trained and compared. On the test set, the Random Forest reached an ROC-AUC of 0.963 and identified 68% of the records with diabetes.

Background from published sources, not results from this dataset:

    Grouping the records

    The K-means algorithm splits the records into three groups based on age, body mass index (BMI) and HbA1c. Whether a record has diabetes is not used for the grouping. The proportion of records with diabetes is then calculated for each group.

      Comparing the models

      Only 8.8% of the records have diabetes, so a high share of correct predictions is not enough to judge a model. The models are compared on ROC-AUC and other metrics such as recall: the share of records with diabetes that a model identifies.

      Explore model predictions

      Change the values to see how each model’s estimate changes. The calculations run locally in your browser. The values you enter are not sent to a server or stored.

      The estimates come from models trained on this dataset only. They have not been clinically validated and do not measure anyone’s actual personal risk of diabetes. The project is for educational use only.

      Methods and checks

      • The data: an initial set of 100,000 records. After removing 3,854 duplicate records and 18 records with “Other” in the gender field, 96,128 records remained. They were split into a training set (80%) and a test set (20%), keeping the same share of records with diabetes in each.
      • The models: a Random Forest (150 trees, depth 7) and a logistic regression, both trained on the training set only. Missing values were filled with averages calculated from the training set alone, so the test set never influenced training.
      • Evaluation: ROC-AUC, recall, precision, F1 and the share of correct predictions (accuracy). Only 8.8% of records have diabetes, so accuracy alone can look high while a model misses cases. Metrics that need a class decision use a 0.5 threshold.
      • Checks: the pipeline has automated tests. On 200 test inputs, the estimates calculated in the browser matched the Python models to within 0.000001.
      • Limitations: the dataset has no information on lifestyle, diet, family history or genetic factors, and the origin of the original records is not documented. The results have not been validated clinically or on an independent population. Neither model is suitable for medical screening.
